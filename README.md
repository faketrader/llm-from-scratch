# LLM from Scratch: Zero to Hero

《大语言模型：从理论到实践》是一套中文学习材料，帮助你理解大语言模型的原理、实现方法与工程系统。内容按五篇42章组织，配套24个实验，涵盖语言模型基础、应用智能体系统、模型训练、训练推理系统及多模态拓展。

“从零”指从基本运算实现模型机制。学习前需具备 Python、线性代数、概率与基础微积分知识；实验还会使用张量、损失函数、梯度下降和神经网络概念。可通过[基础实验](notebook/10_foundations.ipynb)复习这些共同知识。书稿仍在持续校审，欢迎反馈公式、文字和实验中的问题。

## 开始学习

直接打开[在线教材与习题](https://faketrader.github.io/llm-from-scratch/)，按阅读路线选择章节。网站提供目录、全文搜索、公式图表跳转、术语索引和习题解析，首页提供教材与习题 PDF 下载入口。在线阅读无需安装本地编译环境。

三类材料按主题关联，可围绕同一问题交替使用：

| 材料 | 学习用途 | 入口 |
|---|---|---|
| 教材（textbook） | 理解概念、数学推导、教学例题与系统关系 | [在线阅读](https://faketrader.github.io/llm-from-scratch/) |
| 习题（workbook） | 通过习题解析与实验指导 | 在线网站的配套习题与《习题解析与实验指导》PDF |
| 实验（notebook） | 从基本运算实现机制，通过数值或行为证据验证，再迁移到主流库 | [实验目录与学习要求](notebook/README.md) |

建议先读教材并完成相关习题，独立作答后再对照解析，随后选择实验验证自己的理解。章节与实验为多对多关系，可通过[实验目录](notebook/README.md)查找相关主题。PDF 页边的危险弯道图标表示可延后学习的选修内容；书末中英文术语索引可用于回查定义。

## 阅读路线

先学习共同基础：绪论 → 概率、张量与优化的必要知识 → 文本表示 → 注意力与 Transformer → 位置表示 → 自回归生成 → 基本评估与安全。完成后，应能解释一次请求如何从词元输入变成模型输出，说明训练如何更新参数，并识别可检验的效果指标与失败边界。

再按目标进入以下方向。全书按共同基础、应用、模型训练、训练推理系统、模型架构拓展的顺序编排；三条方向可按各自前置选择，方向之间通过具体知识依赖衔接。

| 学习目标 | 建议主线 | 进一步学习 |
|---|---|---|
| 构建大模型应用 | 上下文学习 → 信息检索 → RAG → 领域应用，配合评估与工具安全 | 智能体架构、执行与控制系统（Harness）、持久化与失败恢复 |
| 训练和适配模型 | 数据与监督目标 → 监督微调 → 参数高效微调，配合模型评估 | 预训练、训练稳定性、偏好对齐与可验证推理训练 |
| 部署和优化模型系统 | 资源预算 → 增量解码与缓存 → 批处理调度 → 模型服务 | 推理计算与模型优化；训练系统分支在掌握训练状态后学习分布式训练 |

双向编码、混合专家、长上下文、开放模型与多模态专题按任务选读。

## 使用实验

从[实验目录](notebook/README.md)选择主题，先阅读对应 Notebook 的学习契约，核对先修知识、预计时间、计算资源、依赖版本以及模型和数据准备要求。以 `notebook/` 为工作目录，在支持 Jupyter Notebook 的环境中打开文件。

每个实验沿学习契约、直觉与输入输出、原理实现、证据验证、生产库迁移、生产边界展开。运行时按单元格顺序建立数据与函数依赖；跨实验资产通过文件与 Manifest 传递。环境和资源要求以各文件说明为准，训练、推理及下载操作需在确认成本和运行条件后执行。

完成实验时，重点检查张量形状、数值、梯度、因果性或保存重载结果，并解释库 API 与原理实现之间的对应关系。性能估算需在目标设备上测量校准，单次实验结果的适用范围取决于数据、版本与运行条件。[数值与超参数阅读手册](notebook/HYPERPARAMETERS.md)可帮助理解参数含义和调整依据。

## 本地生成 PDF

需要离线阅读或生成当前源码对应的 PDF 时，安装 GNU Make 和 TeX Live 2026 / MacTeX（含 XeLaTeX、latexmk、ctex、subfiles、xr-hyper、biblatex、Biber、MakeIndex、minted、latexminted 和 algorithmicx），在仓库根目录执行：

```sh
make books
```

教材交付文件为 `dist/textbook.pdf`，习题交付文件为 `dist/workbook.pdf`；LaTeX 中间状态和增量编译缓存保留在 `build/`。两册适合顺序阅读与双面打印，双面打印采用长边翻转。

PDF 构建不依赖 Python。使用 `make figure FIGURE=revision-ch08-architecture` 单独编译一张 TikZ 图片，使用 `make chapter CHAPTER=14-optimization-generalization` 独立编译一章；构建会先更新教材 AUX，章号和跨章引用均按教材主入口中的实际结果自动确定。
